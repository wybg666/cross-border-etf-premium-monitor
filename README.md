# 纳指与标普场内 ETF 折溢价监测

一个轻量的本地网页工具：读取腾讯财经公开行情接口返回的场内价格与 IOPV，计算固定清单内 ETF 的折溢价，展示排序、筛选、报价时点和数据质量状态。

后端使用 Python 标准库，前端使用原生 HTML/CSS/JavaScript，**不需要 npm，也没有前端构建步骤**。不连接券商，不读取个人持仓，不执行交易；无需 API Key、Token 或账号配置。

本项目是非官方参考工具，不保证第三方接口持续可用，也不把显示的折溢价作为可实现收益或交易建议。

## 功能

- 监测 17 只沪深市场 ETF，按纳斯达克 100、纳斯达克科技市值加权、标普 500 分组。
- 展示场内最新价、IOPV、计算折溢价、日涨跌、成交额及买卖价差。
- 按分组、折溢价区间、质量状态和代码/名称筛选，支持表格排序及 Top 5 展示。
- 页面可见时每 30 秒自动刷新，也可手动强制刷新。
- 标记数据缺失、口径异常、行情陈旧、盘后快照及日历未覆盖等状态。
- 默认 `≥ 2%` 作为页面告警阈值。**告警仅指页面标记与筛选，不包含消息推送、声音提醒或自动交易。**

## 安装与启动（Windows）

**请运行项目根目录的 `start.bat` 或 `run.py`，不要双击 `etf_premium/static/index.html` 当作完整程序。** HTML 文件与静态预览不提供 Python 行情接口；直接打开文件会显示启动提示，不会查询行情。正常使用的地址应是终端打印的 `http://127.0.0.1:端口/`，而不是 `file:///...`。

建议使用 **Python 3.11 或更新版本**。启动器最低检查为 Python 3.10；建议版本不代表所有 Python 版本和操作系统都已验证。

唯一列出的第三方依赖是 `tzdata`，用于提供 `Asia/Shanghai` 时区数据，尤其是 Windows 环境。

### 1. 创建环境并安装依赖

下载并解压项目，在**项目根目录**打开 PowerShell，执行：

```powershell
py -3 --version
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

以上命令不需要激活虚拟环境，不需要修改 PowerShell 执行策略。若没有 `py` 命令，但 `python --version` 显示的是所需版本，可以用 `python -m venv .venv` 创建环境。

### 2. 启动服务

```powershell
.\.venv\Scripts\python.exe run.py
```

保持终端打开，然后访问 [本地监测页面](http://127.0.0.1:8765/)。希望同时自动打开浏览器时，可改为：

```powershell
.\.venv\Scripts\python.exe run.py --open-browser
```

默认仅监听 `127.0.0.1:8765`。单纯启动服务不会立即向行情接口请求数据；打开页面或请求行情 API 后才会获取行情。访问健康检查接口不请求行情。

结束使用时，在启动服务的终端按 **Ctrl+C**。关闭网页不等于关闭 Python 服务。

### 3. 端口冲突与快捷启动

如果 `8765` 已被占用，可换端口：

```powershell
.\.venv\Scripts\python.exe run.py --port 8766 --open-browser
```

也支持 `--port 0`，由系统选择空闲端口，以终端打印的地址为准。程序不会为抢占端口而停止其他进程。

`start.bat` 是可选的 Windows 快捷入口，会优先使用项目内 `.venv\Scripts\python.exe`，不存在时再尝试系统的 `py -3` 或 PATH 中的 `python`。它检查 Python 和时区数据后尝试打开页面，**不会自动安装依赖**。完成上述安装后，可以双击它启动。

## 计算口径

```text
折溢价率（%）=（场内最新价 / IOPV − 1）× 100
```

正值为溢价，负值为折价。计算结果保留到小数点后四位，页面展示可能进一步格式化。

当前默认数据源已从失效的东方财富接口改为 **腾讯财经 `https://qt.gtimg.cn/q=`**，启动后不再请求东方财富。一次请求整份 17 只清单。

腾讯返回 `v_sh代码="...~..."` / `v_sz代码="...~..."` 的文本。程序只做字符串解析，不执行返回的 JavaScript；字段索引从 **0** 开始。

| 字段索引 | 本项目解释 |
| --- | --- |
| `3` | 场内最新价 |
| `78` | IOPV 参考估值 |
| `77` | 腾讯提供的溢价率（同号），仅用于核对本地计算 |
| `30` | 行情包时间，`YYYYMMDDHHMMSS`（上海时区） |
| `57` | 成交额（万元），后端乘 10,000 换算为元 |
| `36` | 成交量（手） |
| `9` / `19` | 买一 / 卖一价格 |
| `81` | 腾讯另一净值字段；**不用于 IOPV 计算** |

IOPV / 溢价率 / 净值字段分别由[腾讯基金行情页面](https://gu.qq.com/sh513100)使用的[第一方字段适配代码](https://st.gtimg.com/quotes/hs-fund/bundle.13362df9.js)映射为 `iopv:t[78]`、`yzl:t[77]`、`jz:t[81]`。该网页脚本也可能升级，并非永久稳定的接口承诺。

核对条件为：`abs(计算溢价率 − 腾讯溢价率) ≤ 0.05 个百分点`。超过阈值、关键字段缺失或数值无效时，不给出该行新的溢价计算值，不用零值冒充有效结果。该核对是同一数据源内部一致性检查，不是独立估值验证。

买卖价差按 `(卖一 − 买一) / 买卖中间价 × 100%` 计算，仅在报价有效且卖一不低于买一时展示。

**IOPV 不等于正式单位净值（NAV）**，本工具也不自行用持仓、汇率或期货重建公允价值。字段含义依赖第三方返回口径和腾讯页面适配代码，不能视为数据方提供的稳定接口契约。

## 时间与质量状态

- 页面顶部的**数据生成时间**表示本次结果生成时间，不是行情成交时间，也不是 IOPV 更新时间。
- 腾讯字段 `30` 仅代表行情包时间。**IOPV 没有独立日期或时分秒**，因此 `referenceTime` 为 `null`，不会拿报价日期或本机日期填充它；API 的 `tradeDate` 仅为报价所属日期。
- “报价时效通过”只表示行情包未超过 180 秒，不保证逐笔实时、IOPV 新鲜或报价与估值同步。即使有可计算溢价，也仍需留意这个限制。
- 行情时间明显在未来或盘中超过时效阈值，会标记为陈旧；请同时检查本机时钟。
- 非交易时段展示最近快照；午间或盘后快照不等于当天刚刚更新的数据。
- **延迟数据及日历未覆盖的快照，如果仍可计算数值，仍可能参与排序、最大值和告警统计。** 数值可计算不等于数据新鲜，使用时应结合质量筛选和每行时点。

### 交易日历范围

内置中国市场节假日表仅覆盖 **2026 年**，参考[上海证券交易所休市安排](https://www.sse.com.cn/disclosure/dealinstruc/closed/)。周末视为休市，节假日调休工作日不因此视为交易日。

其他年份明确显示日历未覆盖，不会只凭“周一到周五”宣称当前处于已确认交易时段。`CN_MARKET_EXTRA_HOLIDAYS` 可用逗号分隔的 ISO 日期补充休市日，但不能替代新年度日历维护，也不会自动将未知年份变为已支持年份。

用于质量判断的日内窗口包含开收盘缓冲，不应把它作为精确交易时刻表。

## 刷新、缓存与失败处理

- 当前 17 只一次批量请求腾讯公开行情，不再等待东方财富失败。
- 单次 HTTP 操作配置 5 秒超时、最多 2 次总尝试；这不是对整轮流程总耗时的严格保证。
- 接口结果在进程内缓存 20 秒；页面可见时每 30 秒刷新，隐藏页面暂停自动刷新，重新可见时会很快刷新。
- “立即刷新”使用 `?force=1` 绕过正常 TTL 缓存，仍可能遇到上游错误或等待当前刷新完成。
- 网页 API 显式使用 `allow_stale=False`：刷新失败时不以历史陈旧缓存兜底。**20 秒内的正常缓存命中仍然保留**；内部核心代码也仍保留可选的旧缓存逻辑，不代表相关代码被彻底删除。
- 页面请求有 30 秒客户端超时。接口出错或网络失败时，页面清空上一次表格，避免旧表继续被误认作当前结果；部分缺失会以质量状态和错误提示展示。
- 缓存只在内存中，不提供历史曲线、长期存储、后台推送或持续运行保证。

数据源为腾讯财经 `qt.gtimg.cn` 的公开行情端点。本项目不提供接口可用性承诺；返回字段、访问限制或服务行为变化时可能需要维护，**网页正常启动不代表上游实时数据一定可用**。

## 本地 API

服务运行后可在浏览器访问：

| 地址 | 用途 |
| --- | --- |
| `http://127.0.0.1:8765/api/health` | 检查本地服务是否运行，不调用行情源 |
| `http://127.0.0.1:8765/api/cross-border-etf-premium` | 获取当前结果，可能使用有效期内缓存 |
| `http://127.0.0.1:8765/api/cross-border-etf-premium?force=1` | 强制请求新一轮行情 |

自定义端口后需相应替换地址。行情接口可能以 HTTP 200 返回包含 `ok: false`、`partial` 或 `errors` 的业务结果；调用方应检查响应内容，不能仅用 HTTP 状态判断数据完整。
